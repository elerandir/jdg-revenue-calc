# html_only

Kalkulator w pojedynczym pliku HTML. Nie wymaga żadnych zależności,
serwera ani instalacji — otwiera się podwójnym kliknięciem w przeglądarce.

## Użycie

```
Podwójny klik na index.html
```

Działa na Windows, macOS i Linux bez żadnej konfiguracji.

## Technologie

- HTML5 + CSS Grid (named areas)
- CSS Custom Properties (motywy dziennym/nocny)
- Vanilla JavaScript (zero frameworków)
- Chart.js 4.4 (CDN)
- Google Fonts — Roboto, Roboto Mono (CDN)
